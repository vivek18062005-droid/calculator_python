# 🧮 Advanced Python Calculator

A simple yet powerful **Advanced Calculator built with Python**.
This project provides basic arithmetic operations along with scientific calculations such as square root, factorial, trigonometric functions, percentage, power, and calculation history.

---

## 🚀 Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🔢 Power Calculation
* √ Square Root
* % Percentage Calculation
* ❗ Factorial
* 📐 Sine (Sin)
* 📐 Cosine (Cos)
* 📐 Tangent (Tan)
* 📜 Calculation History
* ⚠️ Error handling for invalid operations
* 🔄 Continuous calculations until the user exits

---

## 🛠️ Technologies Used

* **Python 3**
* **Math Module**
* **VS Code** (recommended)

```bash
python --version
```

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/advanced-python-calculator.git
```

### 2. Open the Project

```bash
cd advanced-python-calculator
```

### 3. Run the Calculator

```bash
python calculator.py
```

---

## 📋 How to Use

After running the program, you will see the following menu:

```text
========================================
        ADVANCED PYTHON CALCULATOR
========================================

1. Addition (+)
2. Subtraction (-)
3. Multiplication (*)
4. Division (/)
5. Power (^)
6. Square Root (√)
7. Percentage (%)
8. Factorial (!)
9. Sin
10. Cos
11. Tan
12. Show History
13. Exit
```

Enter the number corresponding to the operation you want to perform.

### Example

```text
Enter your choice: 1

Enter first number: 25
Enter second number: 15

Result = 40.0
```

### Scientific Calculation Example

```text
Enter your choice: 5

Enter base: 2
Enter power: 10

Result = 1024.0
```

---

## 📜 Calculation History

The calculator stores calculations during the current program session.

Example:

```text
------ CALCULATION HISTORY ------

1. 25.0 + 15.0 = 40.0
2. 10.0 × 5.0 = 50.0
3. 2.0 ^ 10.0 = 1024.0
```

## ⚠️ Error Handling

The program handles some common errors, including:

* Division by zero
* Square root of negative numbers
* Negative factorial
* Invalid menu choices

Example:

```text
Cannot divide by zero!
```
